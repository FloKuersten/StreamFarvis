# StreamFarvis 1.0.1

Replaces the inherited Android launcher artwork with a coral-red ribbon combining an S and a play symbol. The icon uses a charcoal background, keeps safe margins for launcher masks, and includes a monochrome layer for Android themed icons. The startup splash and browser preview favicon use the same artwork.

This is a visual update. Catalog, token storage and playback behavior are unchanged. The release uses the existing StreamFarvis signing identity and can update version 1.0.0 without uninstalling it.

Original artwork and export details are in [resources/branding](../resources/branding/README.md). The build script now takes artifact filenames from the package version.
